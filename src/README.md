# 🚀 Welcome to SmartSpend

> **Know what to pay with. Know what to scan.**

[![Status](https://img.shields.io/badge/status-active-success)](https://smartspend.tech)
[![License](https://img.shields.io/badge/license-MIT-blue)]()

SmartSpend is your intelligent spending companion that helps you compare payment profiles and loyalty programmes to find the **highest estimated reward value** before you spend.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎯 **Smart Recommendations** | Get personalized payment and loyalty card combinations for maximum rewards |
| 💰 **GoodDollar Integration** | Connect your GoodDollar wallet and earn G$ rewards through campaigns |
| 🌍 **Multi-Country Support** | Available in South Africa, Kenya, and expanding globally |
| 📊 **Real-time Analytics** | Track your spending and optimize your rewards instantly |
| 🔒 **Secure & Private** | Your data is protected with enterprise-grade security |

---

## 🚀 Getting Started

### Quick Start

1. **Visit** [smartspend.tech](https://smartspend.tech)
2. **Sign up** or continue as a guest
3. **Add** your payment profiles and loyalty cards
4. **Search** for a retailer and enter your spend amount
5. **Discover** the best recommended combination for maximum rewards

### Example Flow

```
Search Retailer → Enter Amount → Get Best Combo → Save & Earn
```

---

## 🛠 Technology Stack

- **Frontend**: React + Vite + TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Backend**: Base44 Platform
- **Blockchain**: Celo (GoodDollar integration)
- **State Management**: TanStack Query
